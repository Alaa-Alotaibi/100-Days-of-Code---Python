## Project
### Hangman
Build the classic Hangman game where the player guesses letters until they either win or run out of lives.

---

## Main Concepts
- Choosing a random word from a list
- Displaying hidden letters with underscores
- Updating the display when the player guesses correctly
- Reducing lives when the guess is wrong
- Ending the game when the player wins or loses
