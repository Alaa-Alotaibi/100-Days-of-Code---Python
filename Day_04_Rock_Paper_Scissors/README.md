In this project, I created a Rock Paper Scissors game using Python while practicing Python lists, indexing, conditional statements, nested lists, and the random module.

# How the Game Works

The player chooses:

- 0 for Rock
- 1 for Paper
- 2 for Scissors

The computer randomly selects its choice, and the program determines the winner based on the game rules.

## 📚 What I Learned

Through this project, I practiced working with Python lists and how to manipulate and access their data effectively. I learned how to use both positive and negative indexing to retrieve items from a list, which helps when working from either the beginning or end of a dataset.

I also explored how to create and work with nested lists, which are useful for storing structured or grouped data. In addition, I used the `random` module to generate unpredictable computer choices, making the game interactive and dynamic.

Finally, I strengthened my understanding of conditional statements by building the game logic and handling different outcomes, as well as improving input validation to manage incorrect user entries.
