# Code Indentation Quiz

## Question 1

Which version outputs:

```python
This will run
```

Answer:

```python
def my_function():
    print("This will run")

my_function()
```

---

## Question 2

Which version produces an Indentation Error?

Answer:

```python
def my_function():
print("Hello")
```

Reason:

The function body must be indented.

---

## Question 3

Which version prints:

```python
This will run
```

Answer:

```python
def my_function():
    a = 3
    if a > 2:
        print("This will run")

my_function()
```
