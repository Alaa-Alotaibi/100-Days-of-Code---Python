# Day 6 Learning Rules

## Functions

Functions allow you to group code into reusable blocks.

```python
def greet():
    print("Hello")
```

---

## Calling Functions

```python
greet()
```

---

## Why Use Functions?

- Reduce repetition
- Improve readability
- Easier debugging
- Better organization

---

## Indentation

Python uses indentation to define code blocks.

```python
def my_function():
    print("Hello")
```

Incorrect:

```python
def my_function():
print("Hello")
```

---

## While Loops

```python
while not at_goal():
    move()
```

Used when the number of repetitions is unknown.

---

## PEP 8

Official Python style guide:

- Use meaningful names
- Use 4 spaces per indentation level
- Keep code readable
